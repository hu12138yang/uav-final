# MAVLink 控制指令使用说明

## 操控按键

### 实时飞行控制（注意按住生效，松开自动归零）

| 按键 | 轴 | 功能 | 速度值 |
|------|----|------|--------|
| W / S | x | 前飞 / 后飞 | +500 / -500 |
| ← / → | y | 左移 / 右移 | -500 / +500 |
| Q / E | r | 左转 / 右转 | -300 / +300 |
| R / F | z | 上升 / 下降 | +500 / -500 |


### 指令控制（按一次发送3次，间隔50ms）

| 按键 | 功能 | MAV_CMD | 关键参数 |
|------|------|---------|---------|
| A | 解锁 ARM | 400 | param1=1.0 |
| D | 锁定 DISARM | 400 | param1=0.0 |
| T | 起飞 TAKEOFF | 22 | param1=15°, param7=10m |
| L | 降落 LAND | 21 | param1=0 |
